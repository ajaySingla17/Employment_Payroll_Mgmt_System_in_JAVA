Employee Payroll Management System (CSV-based)

Overview:
- Employee module: OOP + Encapsulation
- Payroll module: Inheritance + Polymorphism
- File module: CSV I/O + Exception Handling
- Report module: Stream API + File writing
- Tax module: Slab-wise tax (Encapsulation)

Compile:
  mkdir -p bin
  javac -d bin src/payroll/*.java
Run:
  java -cp bin payroll.Main
